## 🚀 How to Install Plugins

### Claude Code CLI
```bash
# Standard official plugin installation:
claude plugin install <plugin-name>@claude-plugins-official

# Example: Install Superpowers skills suite:
claude plugin install superpowers@claude-plugins-official

# Example: Install Upstash Context7 documentation MCP:
claude plugin install context7@claude-plugins-official

# Example: Install Atlassian MCP server:
claude plugin install atlassian@claude-plugins-official
```

### Claude.ai & Claude Desktop
Navigate to **Customize > Plugins > Discover/Browse**, search for the plugin title, and click **Add**.
