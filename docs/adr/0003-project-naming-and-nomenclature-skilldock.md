# ADR 0003: Official Project Naming & Brand Nomenclature — SkillDock

## Status
**Accepted** (Date: 2026-11-09)

## Context & Problem Statement
The repository was originally titled `Ai-Models-List`. As the project expanded through Milestones H1–H8, it evolved far beyond a passive markdown list into an authoritative registry of 317+ verified skills, autonomous agent harnesses (Superpowers, GSD, Ralph), model routing matrices, MCP toolchains, and developer second-brain systems.

The legacy name `Ai-Models-List` suffered from:
1. Low brand recall and generic appearance (often mistaken for an uncurated notes scratchpad).
2. Failure to capture the dynamic developer workflow (equipping tools, running CLI scripts, and deploying agent stacks).
3. Need for an industry-grade identity suitable for GitHub Pages, CLI tooling, and future custom domain hosting.

---

## Decision Outcome
**Chosen Name: `SkillDock`**

### Rationale:
1. **Developer Metaphor**: In modern computing, a "Dock" is where tools live ready for instant launch (macOS Dock, Docker). Developers and AI agents dock to inspect tools, equip bundles, and launch into their workspaces.
2. **CLI Ergonomics**: Clean two-syllable pronunciation (`skilldock install camerax`, `skilldock sync`).
3. **Numerological Alignment**:
   * **Chaldean 28 ➔ 1**: Governed by the Sun, representing original initiative, leadership, and becoming the #1 standard.
   * **Pythagorean 33 ➔ 6**: Master Number 33 (The Master Builder/Teacher) combined with Venus ($6$) for craftsmanship, visual elegance, and community adoption.

---

## Consequences
- **Branding Update**: The web catalog is branded as **SkillDock — The Launchpad for AI Coding Skills & Agent Harnesses**.
- **CLI Commands**: CLI scripts will support the `skilldock` alias alongside existing Python scripts.
- **Obsidian Vault**: Mirrored under project governance documentation for permanent historical tracking.
