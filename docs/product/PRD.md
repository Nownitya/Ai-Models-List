# PRD — AI Coding Skills and Tools Matrix

## 1. Product Vision
A single, canonical, version-controlled open-source matrix and prompt optimization repository cataloging the world of AI coding skills, agent harnesses, memory frameworks, and developer tools.

## 2. Target Audience
- Software engineers building multiplatform, Android, iOS, and full-stack software with AI pairing.
- AI Agent harness developers configuring custom skills and memory layers.
- Engineering leads standardizing AI tool usage and governance across teams.

## 3. Core Requirements
- **FR-01**: Maintain 16-sheet workbook parity across GitHub Flavored Markdown (`.md`) and CSV (`.csv`) formats.
- **FR-02**: Organize skills into 12 functional domain directories with standardized `SKILL.md` contracts.
- **FR-03**: Provide battle-tested AI prompt optimization frameworks, system prompts, and quality checklists.
- **FR-04**: Provide automated GitHub CLI deployment scripts for zero-friction open-source publishing.
- **FR-05**: Adhere strictly to the Universal Project Documentation Standard (Layer 15).
