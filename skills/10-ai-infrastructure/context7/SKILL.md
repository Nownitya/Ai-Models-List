# Context7

Version-aware documentation and code example retrieval for external libraries.

## When to Use
- Implementing third-party APIs or checking current library usage.

## Core Protocol / Capabilities
1. Query Context7 for target library and version.
2. Extract idiomatic code samples.
3. Verify APIs against project target dependencies.

## Anti-Patterns & Warnings
- Relying on outdated LLM memory for fast-moving libraries.
- Copying unverified examples.
