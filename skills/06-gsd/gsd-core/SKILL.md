# GSD (Get Stuff Done) Core

The structured, goal-backward delivery lifecycle for coding agents.

## Milestone Lifecycle
1. **Discuss**: Unpack user requirements, surface trade-offs, align on architecture.
2. **Plan**: Formulate atomic task plans with dependency waves and verification checks.
3. **Execute**: Atomic story execution with surgical commits and deviation tracking.
4. **Verify**: Goal-backward verification testing against DoD criteria.
5. **Ship**: Release preparation, documentation synchronization, and milestone closing.

## Installation
```bash
npm install -g @open-gsd/gsd-core@next
```
