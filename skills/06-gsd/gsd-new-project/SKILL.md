# Gsd New Project

Initialize a greenfield project with GSD structure, governance, and planning hooks.

## When to Use
- Bootstrapping a new repository.

## Core Protocol / Capabilities
1. Run `gsd new-project`.
2. Define milestones, architecture baseline, and tech stack.
3. Create initial PRD and ROADMAP.

## Anti-Patterns & Warnings
- Skipping milestone definitions.
- Writing code before planning phase 1.
