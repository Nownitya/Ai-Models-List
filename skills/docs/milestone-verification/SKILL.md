# Milestone DoD Verification Report Skill

Standardized engineering skill for creating, updating, and verifying **MILESTONE-VERIFICATION** documentation conforming to Layer 15 Universal Project Documentation Standard.

## When to Use

* Conducting release readiness assessments before production deployment.
* Auditing all milestone exit criteria across functional, perf, and security.
* Securing formal sign-off approvals from architects and product leads.

---

## 🎯 Core Capabilities

* **Capability 1:** Builds comprehensive verification scorecards across all quality domains.
* **Capability 2:** Validates zero high/critical vulnerabilities and benchmark compliance.
* **Capability 3:** Provides signed release approval records for audit trails.

## ⚠️ Anti-Patterns & Warnings

* **Anti-Pattern:** Approving releases with outstanding critical security vulnerabilities.
* **Anti-Pattern:** Accepting subjective opinions instead of empirical benchmark data.
