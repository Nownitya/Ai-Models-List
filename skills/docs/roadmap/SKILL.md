# Product & Engineering Roadmap Skill

Standardized engineering skill for creating, updating, and verifying **ROADMAP** documentation conforming to Layer 15 Universal Project Documentation Standard.

## When to Use

* Sequencing project milestones from foundation (v1.0) to scale (v3.0).
* Setting strict Definition of Done exit gates for milestone transitions.
* Communicating timelines and capability horizons to teams and agents.

---

## 🎯 Core Capabilities

* **Capability 1:** Visualizes milestone horizons with Mermaid flowcharts.
* **Capability 2:** Defines clear exit criteria for each milestone release gate.
* **Capability 3:** Separates core baseline scope from future horizon exploratory tasks.

## ⚠️ Anti-Patterns & Warnings

* **Anti-Pattern:** Moving to subsequent milestones before passing the current exit gate.
* **Anti-Pattern:** Bloating early milestones with speculative, unverified features.
