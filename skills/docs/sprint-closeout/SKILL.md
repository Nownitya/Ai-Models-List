# Sprint Closeout & Outcome Report Skill

Standardized engineering skill for creating, updating, and verifying **SPRINT-CLOSEOUT** documentation conforming to Layer 15 Universal Project Documentation Standard.

## When to Use

* Closing a development sprint and reporting delivered value.
* Documenting delivered story points, pass rates, and PR links.
* Conducting engineering retrospectives (what went well, what to improve).

---

## 🎯 Core Capabilities

* **Capability 1:** Computes velocity delivered vs planned story points.
* **Capability 2:** Compiles factual verification evidence across passing test runs.
* **Capability 3:** Records actionable retrospective learnings for future sprint cycles.

## ⚠️ Anti-Patterns & Warnings

* **Anti-Pattern:** Closing sprints with unverified or partially completed stories.
* **Anti-Pattern:** Omitting links to PRs or automated test execution evidence.
