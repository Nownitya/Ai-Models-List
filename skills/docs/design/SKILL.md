# Technical & UX Design Document Skill

Standardized engineering skill for creating, updating, and verifying **DESIGN** documentation conforming to Layer 15 Universal Project Documentation Standard.

## When to Use

* Designing complex user interactions, sequence flows, and screen transitions.
* Specifying multi-mode UI profiles (e.g. normal vs tactical/emergency mode).
* Defining optimistic UI state updates and asynchronous synchronization.

---

## 🎯 Core Capabilities

* **Capability 1:** Generates Mermaid sequence diagrams for user and backend interactions.
* **Capability 2:** Specifies ergonomic touch targets, contrast ratios, and haptic feedback.
* **Capability 3:** Defines local-first optimistic rendering with server acknowledgment.

## ⚠️ Anti-Patterns & Warnings

* **Anti-Pattern:** Over-complicating user flows with unnecessary modal interruptions.
* **Anti-Pattern:** Failing to design for high-stress, low-visibility, or glove-wearing contexts.
