# Coderabbit

Automated pull request reviews detecting bugs, security vulnerabilities, and missing tests.

## When to Use
- Automating GitHub pull request review cycles.

## Core Protocol / Capabilities
1. Configure `.coderabbit.yaml` review profile.
2. Review automated PR walkthroughs and inline findings.
3. Address flagged security, performance, or logic issues.

## Anti-Patterns & Warnings
- Ignoring critical security findings.
- Over-relying on automated review without human sign-off.
