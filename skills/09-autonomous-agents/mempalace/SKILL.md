# Mempalace

Persistent local-first semantic memory indexing files and transcripts across sessions.

## When to Use
- Preserving durable cross-session learnings, decisions, and trap avoidance.

## Core Protocol / Capabilities
1. Index project artifacts and ADRs into MemPalace.
2. Recall relevant decisions at the start of a session.
3. Curate session diary at milestone ship.

## Anti-Patterns & Warnings
- Indexing transient secrets or tokens.
- Treating memory as a substitute for code git history.
