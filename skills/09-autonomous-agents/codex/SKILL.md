# Codex

OpenAI Codex CLI & APIs for complex coding, repository-wide edits, and script execution.

## When to Use
- Running heavy code refactoring or multi-file code generation.

## Core Protocol / Capabilities
1. Provide scoped prompt with explicit file targets.
2. Inspect diffs generated by the engine.
3. Run local compiler/test gates before committing.

## Anti-Patterns & Warnings
- Blindly applying large unreviewed diffs.
- Running in un-sandboxed environments.
