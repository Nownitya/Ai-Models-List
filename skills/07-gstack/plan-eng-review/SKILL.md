# Plan Eng Review

Comprehensive technical architecture and scalability review before coding.

## When to Use
- Finalizing technical specifications.

## Core Protocol / Capabilities
1. Evaluate data models, network contracts, and latency budgets.
2. Identify single points of failure and race conditions.
3. Approve or revise technical plan.

## Anti-Patterns & Warnings
- Rubber-stamping architectural flaws.
- Over-engineering simple tasks.
