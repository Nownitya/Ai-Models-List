# Review

Review code implementation for bugs, regressions, and quality.

## When to Use
- Post-implementation check before staging.

## Core Protocol / Capabilities
1. Diff changes against base branch.
2. Inspect edge case handling and error logging.
3. Verify all tests pass cleanly.

## Anti-Patterns & Warnings
- Superficial formatting-only reviews.
- Approving unverified changes.
