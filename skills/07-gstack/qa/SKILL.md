# Qa

Perform automated and manual browser-based quality assurance flows.

## When to Use
- Validating end-to-end user workflows.

## Core Protocol / Capabilities
1. Step through user journey end-to-end.
2. Assert UI state changes and API request payloads.
3. Document test run evidence.

## Anti-Patterns & Warnings
- Skipping edge-case inputs.
- Ignoring visual rendering glitches.
