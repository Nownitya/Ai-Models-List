# To Tickets

Break specifications into actionable, atomic development tickets.

## When to Use
- Planning sprint or milestone tasks.

## Core Protocol / Capabilities
1. Each ticket has a unique ID, title, and file targets.
2. Include explicit acceptance criteria.
3. Order tickets by dependency order.

## Anti-Patterns & Warnings
- Giant tickets spanning multiple domains.
- Missing acceptance criteria.
