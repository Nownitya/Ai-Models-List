# Wayfinder

Navigate, orient, and organize complex, multi-file codebases.

## When to Use
- Onboarding or tracing flows across 50+ files.

## Core Protocol / Capabilities
1. Locate main entry points.
2. Trace data flow from input to storage.
3. Document execution maps in `FLOW.md`.

## Anti-Patterns & Warnings
- Getting lost in deep folder hierarchies.
- Speculating on execution paths.
