# Codebase Design

Maintain a well-structured, modular, and maintainable codebase.

## When to Use
- Architecting folder structures and module boundaries.

## Core Protocol / Capabilities
1. Enforce separation of concerns.
2. Keep dependency flow unidirectional.
3. Eliminate circular imports.

## Anti-Patterns & Warnings
- Spaghetti dependencies.
- God objects.
