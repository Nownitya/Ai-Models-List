# Swiftui Expert Skill

Broad SwiftUI reference plus xctrace tooling to record and analyze Instruments traces.

## When to Use
- Profiling iOS view performance, hitches, and memory leaks.

## Core Protocol / Capabilities
1. Capture Time Profiler and SwiftUI update traces via xctrace.
2. Diagnose causes of animation hitches and body re-evaluations.
3. Verify Liquid Glass, accessibility VoiceOver, and Dynamic Type.

## Anti-Patterns & Warnings
- Ignoring VoiceOver labels.
- Speculative SwiftUI performance tuning without Instruments.
