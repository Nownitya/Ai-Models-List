# UI/UX Pro Max (Design Intelligence System)

Searchable design system generator and UI quality guidance covering typography, palettes, layout ergonomics, and component states.

## When to Use
- Designing new screens or complete design systems.
- Selecting cohesive color palettes, typography pairings, and chart visualizations.
- Aligning frontends with technology-specific playbooks (Jetpack Compose, SwiftUI, React, Tailwind).

## Installation & Setup
```bash
npm install -g ui-ux-pro-max-cli
uipro init --ai antigravity
```

## Core Resources
- 79 UI Styles (Glassmorphism, Bento Grid, Neobrutalism, Minimalist OLED).
- 192 domain-specific reasoning rules.
- 22 stack playbooks.
