# UI/UX Pro Max — Quick Reference

Key rules, contrast ratios, and ergonomics standards from UI/UX Pro Max.

---

## 🎨 1. Tactical Color Tokens
- **Pitch Black OLED**: `#000000` (Max battery longevity on OLED mobile screens).
- **Slate Surfaces**: Slate 900 (`#0F172A`), Slate 800 (`#1E293B`).
- **Tactical Amber Accent**: `#F59E0B` (Reserved for active state, PTT transmitting, selection).
- **Status Green**: `#10B981` (Mesh active, online relay).
- **Guarded SOS Crimson**: `#EF4444` (Strictly reserved for emergency alerts).

---

## 📱 2. Ergonomics & Touch Targets
- **Primary Action Actuator (PTT / Trigger)**: Minimum **84dp / 84pt** hitbox with spring animations and continuous haptics.
- **Auxiliary Controls**: Minimum **44dp / 44pt** touch hitbox.
- **Monospaced Telemetry**: Strictly monospaced digits for frequencies, dBFS levels, GPS coordinates, ping latency, and packet drop counts.
- **Zero UI Slop**: Zero decorative emojis in interface chrome; use 100% vector SF Symbols (iOS) or Lucide/Material vector paths (Android).
