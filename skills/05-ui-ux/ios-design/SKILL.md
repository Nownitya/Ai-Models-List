# Ios Design

Build platform-native iOS interfaces adhering strictly to Apple Human Interface Guidelines.

## When to Use
- Designing SwiftUI layouts, sheet presentations, and gestures.

## Core Protocol / Capabilities
1. Follow standard iOS navigation hierarchies.
2. Use vector SF Symbols with semantic color weights.
3. Incorporate tactile haptic feedback on state changes.

## Anti-Patterns & Warnings
- Replicating Android Material Design on iOS.
- Custom non-standard back button behaviors.
