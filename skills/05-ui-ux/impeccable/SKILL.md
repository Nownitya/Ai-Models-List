# Impeccable

24 design commands: critique UX, audit accessibility, polish components, detect UI slop.

## When to Use
- Auditing and refining interface components before production release.

## Core Protocol / Capabilities
1. Run critique command on proposed component.
2. Audit contrast ratios and WCAG accessibility standards.
3. Polish edge cases (empty states, loading skeletons, error states).

## Anti-Patterns & Warnings
- Shipping default generic UI slop.
- Ignoring keyboard navigation and screen readers.
