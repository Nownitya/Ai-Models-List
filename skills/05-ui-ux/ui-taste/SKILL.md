# Ui Taste

Uizze UI Taste: curated real-app screen references, anti-ui-slop guidelines, and radar.

## When to Use
- Seeking design inspiration and benchmarking against top industry apps.

## Core Protocol / Capabilities
1. Search real app screen flows for target pattern.
2. Extract color palettes and typographic hierarchy.
3. Apply anti-slop guidelines (tight spacing, intentional contrast).

## Anti-Patterns & Warnings
- Cloning copyright assets directly.
- Over-decorating functional utility screens.
