# Writing Plans

Create structured, verifiable, and actionable implementation plans.

## When to Use
- Translating specs into executable engineering tasks.

## Core Protocol / Capabilities
1. Decompose features into atomic, testable tasks.
2. Define explicit Definition of Done (DoD) criteria for every step.
3. Map out dependency waves for safe execution.

## Anti-Patterns & Warnings
- Vague milestones without verifiable output commands.
- Bundling 10 files into a single task.
