# Karpathy Guidelines

Apply 4 Karpathy-inspired principles: Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven.

## When to Use
- Pair programming or autonomous coding.

## Core Protocol / Capabilities
1. List explicit assumptions before editing.
2. Choose the simplest primitive solution.
3. Make request-scoped edits only.
4. Validate with terminal proof.

## Anti-Patterns & Warnings
- Premature abstraction.
- Refactoring untouched files.
