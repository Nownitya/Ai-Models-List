# Brainstorming

Explore requirements, alternatives, and technical trade-offs before writing code.

## When to Use
- Starting any non-trivial feature, architectural shift, or redesign.

## Core Protocol / Capabilities
1. Clarify core goals and user personas.
2. Enumerate at least 3 distinct implementation approaches with pros/cons.
3. Record assumptions and obtain human alignment before drafting code.

## Anti-Patterns & Warnings
- Jumping straight to code without understanding scope.
- Ignoring edge-case constraints.
